# Rick Jacoby

Product leader in life insurance and annuities, now working on AI evaluation and applied ML. MBA, MFIN with data analytics, and graduate AI coursework at Penn State.

Most of these repos come back to one question: how do you know a model is actually working? I set honest baselines, test on the path the model really runs, and read the errors before the headline number.

## Pinned work

| Repo | What it shows |
|---|---|
| [transformer-spell-checker](https://github.com/espressoLearn/transformer-spell-checker) | Caught a model that looked healthy in training but made text worse at inference, by scoring real output against a copy-the-input baseline. CER from 0.386 to 0.022 |
| [bert-sentiment-eval](https://github.com/espressoLearn/bert-sentiment-eval) | Run monitoring and alerts, confidence-ranked error analysis, and cost against quality on BERT base vs large |

| [ny-real-estate-price-model](https://github.com/espressoLearn/ny-real-estate-price-model) | New York home prices in R: zipcodeR data enrichment, H2O random forest (test RMSE $42K), Tableau dashboard |
